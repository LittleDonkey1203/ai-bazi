输入数据为一个长度为 8 的字符串数组 `bazi_input`，例如 `["戊", "寅", "乙", "卯", "乙", "亥", "壬", "午"]`。

## 模块 3：虚浮与通根判定 (Rooting Verification)
天干力量需要地支支撑。
1. 遍历 年干(0)、月干(2)、时干(6)。获取其五行属性。
2. 扫描原局的四个地支(1, 3, 5, 7)对应的 `HIDDEN_STEMS` 字典。
3. 如果这四个藏干对象中，**完全不存在**该天干的五行（即连 0.1 的余气都没有），则判定该天干「虚浮」。
4. 惩罚：将该天干在模块 2 中贡献的分数，从总分中 **减去 50%**。

地支突变必须严格遵循中国命理学经典力量排序：三会 > 三合 > 六合 > 半合 > 冲。

**P1：三会局 (Directional - 最高统治力)**

- 执行：若全齐，强制转移 100% 分数至目标五行，目标五行额外 +20% 分。打上 `is_used` 锁。不受月令否决。

**P2：三合局 (Trine - 完整成局)**
- `[亥卯未]`->木, `[寅午戌]`->火, `[巳酉丑]`->金, `[申子辰]`->水。

**P3：六合局 (Six Harmonies - 天地紧密之合)**

**P4：半合局 (Half-Trine - 必须包含中神 卯/午/酉/子)**

## 模块 6：季节能量乘数 (Seasonal Multipliers - 核心重构)
在算完前5个模块后，执行最终分数加权。
获取【月支(Index 3)】的主气五行（即 `HIDDEN_STEMS` 中占比最高的五行），记为 `Month_Element`。
遍历当前的 `{金,木,水,火,土}` 分数，乘以对应系数：
- 与 `Month_Element` 相同 (旺): `Score * 1.5`
- 被 `Month_Element` 所生 (相): `Score * 1.2`
- 生 `Month_Element` (休): `Score * 0.9`
- 克 `Month_Element` (囚): `Score * 0.8`
- 被 `Month_Element` 所克 (死): `Score * 0.5`

## 模块 7：格局判定分类器 (Pattern Classifier)
**最高优先级拦截：化气格 (Transformation)**
- 条件：日主(4)与相邻干存在五合；且合化【目标五行】== `Month_Element`；且原局天干无克制【目标五行】的元素。
- 执行：若满足，日主五行变更为【目标五行】。`return "化气格"`, Yong=[目标五行, 生目标五行], Ji=[克目标五行]。程序直接跳至最终输出。

**常规判定：**
将加权后的五行得分分为：
- 同党 (Self)：日干五行 + 生日干五行。
- 异党 (Opposing)：其余三者。
规则树：
1. `同党 >= 85%`: return "专旺格"
2. `同党 <= 15%`: return "从格"
3. `同党 > 50%`: return "身旺格"
4. `同党 <= 50%`: return "身弱格"

## 模块 7 升级：格局判定分类器 (Pattern Classifier - 假从/假专修复补丁)

原有的 15% 阈值过于严格，无法处理命理学中的“假从格”与“假专旺格”。我们需要引入单边统治力检测（Dominant Element Check）。

请重新编写格局分类树的逻辑，按以下严格优先级执行：

**前置计算：**
1. 获取所有五行的总分 (Total_Score)。
2. 计算【同党百分比】: `(日干五行得分 + 生日干五行得分) / Total_Score * 100`。
3. 计算【异党中得分最高的单一五行百分比】，记为 `Max_Opposing_Percent`。
4. 计算【同党中得分最高的单一五行百分比】，记为 `Max_Self_Percent`。

**最高优先级拦截：化气格 (Transformation)**
- 条件：日主(4)与相邻干存在五合；且合化【目标五行】== `Month_Element`；且原局天干无克制【目标五行】的元素。
- 执行：变更日主五行，`return "化气格"`, Yong=[目标五行, 生目标五行], Ji=[克目标五行]。

**第二优先级：特殊格局 (Special Patterns) - 包含真假从、真假专**
1. `IF 同党百分比 >= 85`: 
   - `return "专旺格"`
2. `IF 同党百分比 >= 70 AND Max_Self_Percent >= 65`:
   - (假专旺：即使异党有一点抵抗，但某一同党五行统治力极强)
   - `return "假专旺格" (Treat as 专旺格)`
3. `IF 同党百分比 <= 15`: 
   - `return "从格"`
4. `IF 同党百分比 > 15 AND 同党百分比 <= 30 AND Max_Opposing_Percent >= 65`:
   - (假从格修复：同党虽有 15%-30% 的残存力量，但异党的某一五行占据了 65% 以上的绝对统治地位，导致日主被迫盲从)
   - `return "假从格" (Treat as 从格)`

**第三优先级：常规格局 (Normal Patterns)**
*(如果未被上述任何特殊格局捕获，则进入常规比对)*
1. `IF 同党百分比 > 50`: 
   - `return "身旺格"`
2. `IF 同党百分比 <= 50`: 
   - `return "身弱格"`
