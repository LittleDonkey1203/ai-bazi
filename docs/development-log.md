### 修复八字命例 `id` 被 `undefined` 覆盖导致始终只剩一条
- 根因在 `caseStorage.ts`：
  - 保存新命例时先生成了 `id`
  - 但随后对象展开 `...input` 又把 `id: undefined` 覆盖回去
  - 结果新建命例实际都变成“无 id 记录”，下一次保存时会把上一条无 id 记录顶掉
- 已修复为先拆出 `id`，再组装 `nextRecord`
- 同时给 `getBaziCases()` 增加旧数据迁移：
  - 发现历史记录缺少 `id` 时自动补发新 `id`
  - 迁移后立即回写本地存储，避免旧脏数据继续影响新增/删除/载入

### 修复八字命例管理“保存新命例覆盖旧命例”
- `BaZiPage.tsx` 将命例保存拆成两条显式路径：
  - 有当前命例时，`更新当前命例`
  - 需要保留原记录时，`另存为新命例`
- 原因是此前保存后会持续保留 `activeCaseId`，用户继续录入再点保存时会直接更新同一条记录，视觉上就像“只能保存一个命例”
- 同时抽出了 `buildCaseDraft(...)`，避免更新和另存为新命例走两套不一致的保存参数
