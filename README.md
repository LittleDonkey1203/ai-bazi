# new_prj Workspace

这个仓库现在是一个 monorepo，根目录统一管理两个可部署服务：

- `zhouwenwang/zhouwenwang-divination`
- `bazi-mcp`

## 常用命令

```bash
npm run bootstrap
npm run build
npm run dev:app
npm run dev:app:backend
npm run start:mcp
```
